# BinGo Resident Mobile App

Expo / React Native application for residents in municipal waste collection zones.

## Features
- **Household Login**: Enter household ID (e.g. `HH-101`)
- **Interactive BinGo Card**: 5-square waste card (`wet`, `sanitary`, `dry`, `furniture`, `event`)
- **Bay QR Scanner**: Scan rotating bay QR codes or paste token deep links
- **Green-Tick Confirmation**: Immediate scan validation with vehicle load progress bar
- **Out-of-Station Mode**: Toggle temporary absence to suppress missed-disposal alerts
- **Disposal History**: Chronological log of recorded deposits

## Development
```bash
npm install
npx expo start
```
